Frequently Asked

Why is it saying "Not Whitelisted"?

To prevent random people from joining, we only allow NWIS students. You must join the WhatsApp group and send your username to the Admin to be added.

How do I earn money?

Type /jobs browse in the chat. Pick a job like "Miner" or "Woodcutter". You will start earning coins for every block you break!

What version should I use?

The server runs on 1.20.1, but thanks to ViaBackwards, you can join using almost any modern version of Minecraft.

My console doesn't have an "Add Server" button!

This is a limitation by Sony/Microsoft. You must use the BedrockTogether app or a DNS bypass to join custom IP servers on consoles.
